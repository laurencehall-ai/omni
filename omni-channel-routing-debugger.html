One-time setup instructions ▸

Complete these steps once in your Salesforce org, then enter the values above.

  1. Create a Connected App — Setup → App Manager → New Connected App
    • Check Enable OAuth Settings
    • Callback URL:
    • OAuth Scopes: add Access and manage your data (api) and Perform requests at any time (refresh_token)
    • Check Require Proof Key for Code Exchange (PKCE)
    • Save, then copy the Consumer Key — that's your Client ID above
  2. Allow CORS — Setup → Security → CORS → New
    • Origin URL:
  3. Serve this file locally — the OAuth callback won't work from file://
    • In your terminal: python3 -m http.server 8000 (from the folder containing this file)
    • Then open: http://localhost:8000/omni-channel-routing-debugger.html
